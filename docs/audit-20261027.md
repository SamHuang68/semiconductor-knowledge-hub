# Semiconductor Knowledge Hub 稽核（2026-10-27）

稽核對象：本機 `main` 對應的公開站 [https://samhuang68.github.io/semiconductor-knowledge-hub/#explore](https://samhuang68.github.io/semiconductor-knowledge-hub/#explore)，以及章節、附錄、全景圖、行話字典、全域檢索。

量測方式：Chrome headless，視窗 360 / 390 / 768 / 1280。頁面包含 `#explore`、五個情境深連結、`#ch00`、`#ch04`、`#ch12`、`#ch21`、`#app-glossary`。對比用頁面計算的前景／背景相對明度（WCAG 2.1，一般文字門檻 4.5:1）。外部連結以 HTTP 狀態複核。未改寫技術事實；`data/chapters-data.js`、`data/fab-flow.js`、`data/glossary-data.js`、`data/search-index.js` 的內容雜湊維持鎖定。

## P0 發現與批次 1 處置

### 斷鏈

- 附錄 A 的 `TRANSLATIONS.md` 被寫成 `blob/main/...`。上游預設分支是 `master`，`main` 回 404。相對路徑 `../../TRANSLATIONS.md` 也指到同一條死連結。批次 1 在 `normalizeChapterHref()` 統一改寫到 `blob/master/TRANSLATIONS.md`，不改鎖定的教材檔。
- 第 13 章 DRAM 註記的 Micron「DDR5 SDRAM: New Features」白皮書，舊位址 `my.micron.com/.../ddr5-new-features-white-paper.pdf` 回 404。已改為 Micron 資產網址（同一份白皮書，刷新命令與 tREFI 仍在第 2 頁）。連結文字未改。
- 抽過的其餘外部連結（創用 CC、上游倉庫、Portal、NVM Hub、公開站首頁）回 200。章節 hash 與 28 張實體照片路徑沒有缺檔。

### 無障礙

- `#chapterFilter`、`#searchModalInput`、`#jargonSearchInput` 只有 placeholder，沒有可計算的無障礙名稱。已補 `aria-label`，並跟語言切換。
- 主題、全景圖、字典、檢索、快捷鍵、字級按鈕在窄螢幕會把可見文字 `display: none`，名稱只剩 `title`。已改為明確的 `aria-label`。
- 手機目錄鈕沒有 `aria-expanded` / `aria-controls`。抽屜用 `translateX(-100%)` 藏起來，但連結仍在 Tab 順序裡。關閉時對抽屜設 `inert`，開啟時隔離主文與頁尾，焦點移到章節過濾框。
- 側欄篩選與字典分頁沒有 `aria-pressed`。學習進度條沒有 `progressbar`。已補上。
- 沒有「跳至主要內容」。已加視覺上隱藏、聚焦才出現的 skip link。
- 檢索結果的標題是 `div`，鍵盤只能點到旁邊兩個小按鈕。標題改成按鈕；結果數量寫進 `aria-live`；在檢索彈窗內可用上下鍵移動。
- 寬表格包在 `overflow-x: auto` 裡，鍵盤無法把焦點放進捲動區。載入章節時把 `.table-container` 設成可聚焦的 `region`。
- 音效鈕沒有反映開／關。已加 `aria-pressed` 與狀態文字。
- 對比（亮色主題，修正前）：
  - 品牌副標、白字主按鈕、側欄分頁：`#0284c7` 對白約 4.1:1，11–13px 低於 4.5:1。
  - 進度數字約 3.7:1。快捷鍵徽章約 4.3:1。
  - 全景圖遙測 `#94a3b8` 對 `#f1f5f9` 約 2.3:1；狀態徽章 `#34d399` 對淺綠底約 1.3:1。
- 批次 1 把亮色 `--semi-blue` 調成 `#075985`（對白 7.56:1），黃光主題的同名 token 調成 `#9a3412`，遙測與徽章改為深色字配淺底。頁面底色仍符合規則 0003。

### 導覽與 RWD

- 1200px 以下整塊 `.app-toc`（含字級按鈕）被 `display: none`。390px 讀章時無法調字，也沒有本頁大綱。批次 1 在 1200px 以下改成右下角可收合的固定面板，預設收合，字級按鈕保持可見。情境探索頁原本就隱藏這塊面板，維持不變。
- 860px 以下頁首「情境探索」被整顆隱藏，只能先開抽屜。已恢復頁首入口；768px 以下工具列允許換行，並用頁首實際高度更新 `--header-offset`，避免抽屜蓋住長高的頁首。
- 複測：360 / 390 / 768 / 1280 的 `#explore` 與章節頁 `scrollWidth` 不大於視窗。360px 頁首高度 128px，可見按鈕都在頁首框內。
- 1280px 的寬表仍在容器內橫向捲動，頁面本身不橫向溢出。這是既有表格策略，批次 1 只補鍵盤可達性。

### 搜尋

- 索引是 28 筆章節關鍵字（`data/search-index.js`），不是章節全文。查「CMP」可回到章，但查正文裡的冷門句子會落空。列為批次 3，避免在這一批改鎖定的索引檔。

## 視覺改版計畫（批次 2）

目標：矽製程企業識別，仍遵守淡色底（規則 0003），不新增深色主題。

1. 小型設計系統：顏色、字級、間距 token，以及頁首、按鈕、卡片、圖說等可重用元件。
2. 探索頁與章節殼層的字級層級、留白、卡片對齊。
3. 以結構正確的 SVG 取代薄弱示意：圖形轉移剖面（基板／目標膜／光阻，標明未按比例）、封裝並排、12 站製程流（名稱來自既有 `FAB_FLOW_NODES`）。
4. 圖表只使用倉庫裡數得出的數量，或已公開、可引用的標準表。每張圖標來源。不發明量測值。
5. 高品質生成圖的預留位置。檔名、提示詞與 alt 寫在 `docs/image-briefs-20261027.md`。圖未到之前顯示預留框；到圖之後標成示意，不當成量測影像。

批次 2 落點：`design-tokens.css` 與 `design-system.css` 提供顏色、字級、間距與卡片元件；探索頁在教材入口前插入 12 站教學流、兩張有出處的橫向長條圖，以及六個示意圖框。長條用 HTML，避免 SVG 在窄螢幕把數字縮到看不清。潔淨室圖取 ISO 14644-1:2015 Table 1 的 ≥0.5 µm 表列值，長條長度是對數；Class 1 與 Class 2 在該表此粒徑標為不適用（註 d），所以不畫，並列入表中有上限的 Class 9。章節數來自 `data/chapters-data.js` 的 `part` 計數。剖面、封裝與旅程 SVG 標明未按比例，並保留圖形轉移第 3 步的「下方薄膜仍完整」。目前節點改成淺青綠底與深字，不再用白字壓在深色塊上。

### 批次 6 已處理

- 分部頁 `#part/...` 的每一章是一張可鍵盤聚焦的卡片。摘要取自檢索索引裡既有的「本章：」或 “This chapter:”，沒有新寫介紹句。

- 不明的 hash 不再改開第 0 章，而是站內找不到頁面，並標 `noindex`。倉庫根目錄的 `404.html` 給 GitHub Pages 的路徑 404 使用，中英都看得到出路。
